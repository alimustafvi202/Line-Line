Clinical Methodology & Rigorous Evaluation Standards

1. Zero-Phase Bandpass Filtering

Raw ECG leads are filtered using a 3rd-order digital Butterworth bandpass filter (0.5 Hz – 40.0 Hz) with zero phase distortion (scipy.signal.filtfilt). This removes respiration baseline drift and 50/60 Hz powerline interference without shifting R-peak locations.

2. Data Leakage Prevention (De Chazal 2004)

We enforce a strict inter-patient partition. Naive random heartbeat splitting produces artificially inflated scores (>98%) because heartbeats from the same patient share morphological quirks. In this system, testing is performed exclusively on unseen patients from the DS2 cohort.

3. AAMI EC57 5-Class Super-Group Standard

Annotation symbols from PhysioNet MIT-BIH recordings are mapped into: N (Non-Ectopic), S (Supraventricular Ectopic), V (Ventricular Ectopic), F (Fusion), and Q (Unknown / Paced). Spurious non-beat markers (+, ~, comments) are completely discarded.

4. Lightweight 1D-CNN Architecture

A 4-block 1D-CNN with Batch Normalization, Max-Pooling, Dropout, and Global Adaptive Average Pooling (109,861 trainable parameters). It performs real-time heartbeat anomaly inference in under 20 milliseconds on standard CPU hardware.
